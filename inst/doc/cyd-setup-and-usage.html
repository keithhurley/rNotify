Using the Cheap Yellow Display (CYD) with rNotify

Keith Hurley

2026-10-07

Introduction

The Cheap Yellow Display (CYD) is a popular, low-cost (approx. $10–$15) ESP32-based development board featuring an integrated 2.8” color TFT screen.

When paired with rNotify, the CYD acts as a dedicated, physical desk monitor for your R jobs. It renders high-frequency outer and nested inner progress bars, color-coded job status, elapsed runtime, and real-time ETAs without cluttering your workstation screens or flooding your phone with push notifications.

rNotify supports three flexible transports for driving the CYD: 1. Bluetooth Serial (SPP): Direct wireless link from your computer to the desk display. No Wi-Fi networks, router isolation, or passwords required! 2. USB Serial: Direct wired connection over the micro-USB cable. Zero configuration, instant plug-and-play. 3. Wi-Fi REST: Over local network via lightweight HTTP POST requests.

1. Hardware Specifications & Pinout

Technical Specifications

  • Module Model: ESP32-2432S028R
  • Processor: Dual-core ESP32-WROOM-32 (240 MHz, 520 KB SRAM, 4 MB Flash)
  • Display: 2.8-inch TFT LCD, 320 × 240 pixels (Landscape)
  • Display Controller: ILI9341 (SPI interface)
  • Touch Controller: XPT2046 resistive touch
  • Wireless: Bluetooth Classic (SPP), Bluetooth Low Energy (BLE), 2.4 GHz Wi-Fi
  • Power & Data: Micro-USB (5V, 500mA–1A)
  • Peripherals: Onboard RGB LED (Pins 4, 16, 17), LDR light sensor, MicroSD slot, speaker header

Pinout Table (ESP32 to LCD & LED)

Signal ESP32 GPIO Pin Description
TFT_MISO GPIO 12 SPI Master In Slave Out
TFT_MOSI GPIO 13 SPI Master Out Slave In
TFT_SCLK GPIO 14 SPI Clock
TFT_CS GPIO 15 LCD Chip Select
TFT_DC GPIO 2 Data / Command Control
TFT_RST -1 Tied to ESP32 EN/Reset
TFT_BL GPIO 21 Backlight LED Control (Active HIGH)
LED_RED GPIO 4 Onboard RGB LED - Red (Active LOW)
LED_GREEN GPIO 16 Onboard RGB LED - Green (Active LOW)
LED_BLUE GPIO 17 Onboard RGB LED - Blue (Active LOW)

2. Firmware Flashing & Configuration

rNotify provides pre-written, ready-to-flash Arduino firmware inside the package at inst/cyd_firmware/cyd_notify.ino.

Step 1: Arduino IDE / Arduino CLI Configuration

  1. Open the Arduino IDE (v2.x) or install arduino-cli.
  2. Ensure the ESP32 board package is installed:
    • Board: ESP32 Dev Module (esp32:esp32:esp32).
    • Partition Scheme: Select Huge APP (3MB No OTA / 1MB SPIFFS) to ensure ample headroom for Bluetooth and display drivers.

Step 2: Install Required Libraries

Open Tools > Manage Libraries… (or run arduino-cli lib install): - TFT_eSPI (by Bodmer) - ArduinoJson (by Benoît Blanchon, v6 or v7) - BluetoothSerial (included automatically in the ESP32 board core)

Step 3: Configure TFT_eSPI for CYD

In your computer’s Arduino libraries folder, locate libraries/TFT_eSPI/User_Setup.h:

#define ILI9341_2_DRIVER

#define TFT_WIDTH  240
#define TFT_HEIGHT 320

#define TFT_BL   21            // LED back-light control pin
#define TFT_BACKLIGHT_ON HIGH  // Level to turn ON back-light

#define TFT_MISO 12
#define TFT_MOSI 13
#define TFT_SCLK 14
#define TFT_CS   15
#define TFT_DC    2
#define TFT_RST  -1

#define LOAD_GLCD
#define LOAD_FONT2
#define LOAD_FONT4
#define LOAD_FONT6
#define LOAD_FONT7
#define LOAD_FONT8
#define LOAD_GFXFF
#define SMOOTH_FONT

#define SPI_FREQUENCY  40000000

Step 4: Flash the Firmware

  1. Open inst/cyd_firmware/cyd_notify.ino.
  2. Connect your CYD via micro-USB.
  3. Select your serial port (e.g. COM7) and upload.
  4. Once flashed, the screen initializes and displays BLUETOOTH READY with device name rNotify-CYD.

3. Bluetooth Pairing Setup

To use the CYD wirelessly via Bluetooth from inside R:

Windows

  1. Open Windows Settings > Bluetooth & devices.

  2. Click Add device > Bluetooth.

  3. Select rNotify-CYD from the discovered device list and pair.

  4. Open More Bluetooth settings > COM Ports tab (or check Device Manager under Ports (COM & LPT)) to find the assigned Outgoing COM Port (typically COM8 or COM9).

  5. Save the port in your ~/.Renviron:

    CYD_BT_PORT=COM8

macOS

  1. Open System Settings > Bluetooth.
  2. Pair with rNotify-CYD.
  3. A serial device appears at /dev/tty.rNotify-CYD.

Linux

  1. Pair using bluetoothctl:

    bluetoothctl
scan on
pair <MAC_ADDRESS>

  2. Bind the RFCOMM port:

    sudo rfcomm bind 0 <MAC_ADDRESS> 1

  3. Use /dev/rfcomm0 in R.

4. Driving the CYD from R

Method A: Wireless via Bluetooth (Recommended)

library(rNotify)

# Connect to paired Bluetooth CYD
cyd <- channel_cyd_bluetooth(port = "COM8")

# Run job with live telemetry
job <- notify_job(
  title = "Creel Model Bootstrap",
  channels = list(cyd, channel_desktop()),
  total_steps = 50
)

job$start("Starting bootstrap iterations...")

for (i in 1:50) {
  Sys.sleep(0.1)
  notify_step(job, step = i, message = sprintf("Processing replicate %d / 50", i))
}

job$complete("All iterations converged successfully.")

Method B: Wired via USB Serial

If your CYD is plugged directly into a USB port on your workstation:

library(rNotify)

# Directly access the USB serial port
cyd <- channel_cyd_serial(port = "COM7")

job <- notify_job(
  title = "Local Analysis",
  channels = cyd,
  total_steps = 100
)

for (i in 1:100) {
  Sys.sleep(0.05)
  notify_step(job, step = i)
}

job$complete()

Method C: Over Wi-Fi (HTTP)

If you prefer operating over local network Wi-Fi:

library(rNotify)

# Point to the CYD's Wi-Fi IP address
cyd <- channel_cyd(host = "192.168.1.150")

job <- notify_job(
  title = "Cluster Simulation",
  channels = cyd
)

5. Nested Loops & Subtask Telemetry

The CYD firmware features a dedicated inner subtask progress bar specifically designed for nested algorithms (such as bootstrap replicates within each parameter set, or folds within cross-validation).

library(rNotify)

cyd <- channel_cyd_bluetooth("COM8")

job <- notify_job(
  title = "Statewide Creel Index",
  channels = list(cyd, channel_desktop()),
  total_steps = 10
)

job$start("Starting statewide run...")

for (i in 1:10) {
  # Subtask initializes nested progress bar on CYD screen
  sub <- job$subtask(title = sprintf("Lake %d", i), total_steps = 100, step_num = i)

  for (j in 1:100) {
    Sys.sleep(0.02)
    sub$progress(step = j, message = sprintf("Iteration %d", j))
  }

  sub$complete()
}

job$complete("Finished statewide analysis.")

6. Onboard Status Indicators & Protocol

RGB LED Feedback

The CYD onboard RGB LED mirrors your job lifecycle: - Idle / Ready: Soft Cyan / Blue - Running (start, progress, step): Vibrant Blue / Cyan - Complete (complete): Bright Green - Failure / Crash (error, catastrophic): High-visibility Red

Serial & JSON Protocol

channel_cyd sends newline-terminated JSON strings over Bluetooth and USB Serial at 115200 baud:

{
  "title": "Statewide Creel Index",
  "event": "progress",
  "status_text": "RUNNING",
  "status_color": "#33DD66",
  "progress_pct": 24,
  "step_info": "12 / 50",
  "inner_pct": 45,
  "inner_info": "450 / 1000",
  "message": "Fitting Lake McConaughy",
  "elapsed": "01:14:22",
  "eta": "04:02:10",
  "channels": ["cyd", "desktop"]
}

Upon receiving each valid payload, the CYD immediately updates its canvas and returns {"status":"ok"}.
